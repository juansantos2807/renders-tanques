# Renders de tanques – Sistema C.O.T.A.

## Dónde va cada archivo
- modelos/  → modelos 3D (.glb)
- planos/   → planos en planta (.svg o .png)

## Cómo nombrar los archivos
- Todo en minúsculas, guiones en lugar de espacios, sin acentos ni ñ.
- El modelo y el plano de un tanque llevan el MISMO nombre:
  modelos/pirules-1.glb  y  planos/pirules-1.svg
- Así el sistema los sugiere solo al escribir el nombre del tanque.

## Reglas
- Un archivo por tanque. No subir fotos aquí (las fotos 360° van en Drive).
- Tamaño máximo recomendado: 30 MB por archivo.
- Para reemplazar un modelo, sube el nuevo con el mismo nombre (GitHub guarda la versión anterior).
